# Spine Event 配置指南

## 核心动画事件配置

### 1. 攻击动画 (attack)
- **attack_hit** - 在攻击命中帧添加此事件
  - 位置：攻击动作的关键帧（如挥剑到底、拳头接触等）
  - 用途：触发伤害计算和命中判定

### 2. 受击动画 (hit)
- **无需特殊事件** - 动画完成自动返回待机

### 3. 死亡动画 (death)
- **death_complete** - 在死亡动画完成时添加
  - 位置：角色完全倒下的帧
  - 用途：开始尸体淡出流程

### 4. 昏迷动画 (unconscious)
- **unconscious_start** - 昏迷开始时
  - 位置：角色开始倒下的帧
  - 用途：启动昏迷恢复系统

### 5. 待机动画 (idle)
- **无需特殊事件** - 循环播放

### 6. 行走动画 (walk/run)
- **无需特殊事件** - 循环播放

## 事件命名规范
- 使用小写字母和下划线
- 事件名称要有明确含义
- 避免使用数字开头

## 在Spine中添加事件步骤
1. 选择动画时间轴
2. 在关键帧位置右键 -> Add Event
3. 输入事件名称（如：attack_hit）
4. 可选：添加事件数据（字符串、整数、浮点数）

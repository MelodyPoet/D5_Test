## 🔄 2. 战斗动画调用完整链路

### 2.1 战斗初始化阶段

**文件**: `HorizontalBattleFormationManager.cs` / `AutoBattleAI.cs`

```csharp
// 步骤 1: 战斗启动入口
public void StartBattleSequence()
{
    // 1.1 收集所有参战角色
    var allCombatants = new List<CharacterStats>();
    CharacterStats[] allCharacters = FindObjectsOfType<CharacterStats>();
    
    // 1.2 执行先攻检定 - 核心！
    initiativeOrder = HorizontalCombatRules.RollAndSortInitiative(allCombatants);
    
    // 1.3 启动回合循环
    currentTurnIndex = 0;
    isBattleActive = true;
    StartNextTurn();
}
```

**关键点**:
- `HorizontalCombatRules.RollAndSortInitiative()` 执行先攻掷骰（d20 + 敏捷修正）
- 返回按先攻值降序排列的 `List<InitiativeEntry>`
- 进入 `Update()` 循环，按 `decisionDelay` 定时器触发 `ProcessCurrentTurn()`

### 2.2 回合处理阶段

**文件**: `AutoBattleAI.cs`

```csharp
// 步骤 2: 处理单个角色的回合
private void ProcessCurrentTurn()
{
    var currentEntry = GetCurrentInitiativeEntry();
    
    // 2.1 检查角色是否可以行动
    if (!currentEntry.CanAct()) {
        AdvanceToNextTurn();
        return;
    }
    
    // 2.2 如果角色昏迷，执行死亡豁免
    if (character.HasStatusEffect(StatusEffectType.Unconscious)) {
        character.PerformDeathSaveTick();
        AdvanceToNextTurn();
        return;
    }
    
    // 2.3 选择最佳行动
    var chosenAction = DecideBestAction(character);
    
    // 2.4 执行行动 - 核心！
    ExecuteBattleActionEvent(character, chosenAction, () => {
        currentEntry.MarkAsActed();
        AdvanceToNextTurn();
    });
}
```

**关键点**:
- 检查终止状态（死亡/昏迷）
- `DecideBestAction()` 基于 AI 优先级选择目标
- 执行 `ExecuteBattleActionEvent()` 分发到具体动画系统

### 2.3 动画执行阶段（近战 vs 远程）

**文件**: `AutoBattleAI.cs` → `DND_CharacterAdapter.cs`

#### 2.3.1 近战攻击流程

```csharp
// 步骤 3a: 近战攻击分发
private void ExecuteBattleActionEvent(CharacterStats attacker, BattleAction action, System.Action onComplete)
{
    bool isMeleeAttack = IsCharacterInFrontRow(attacker);  // 判断前排=近战
    
    if (isMeleeAttack) {
        var attackerAdapter = attacker.GetComponent<DND_CharacterAdapter>();
        
        // 3a.1 执行近战攻击 - 含位移动画
        attackerAdapter.ExecuteMeleeAttack(
            action.target.transform,
            onAttackHit: () => {
                ProcessAttackHit(attacker, action.target, true);  // 命中时处理伤害
            },
            onComplete: () => {
                onComplete?.Invoke();  // 回合完成，进入下一个角色
            }
        );
    }
}

// 步骤 3a.2: 近战攻击执行（带位移）
public void ExecuteMeleeAttack(Transform target, System.Action onAttackHit = null, System.Action onComplete = null)
{
    isAnimating = true;
    
    // 阶段1: 计算攻击位置
    Vector3 attackPosition = CalculateAttackPosition(target);  // 目标前方 attackDistance 距离
    
    // 阶段2: 播放走动动画并移动到攻击位置
    PlayWalkAnimation();
    float moveDistance = Vector3.Distance(transform.position, attackPosition);
    float moveDuration = moveDistance / animationConfig.moveSpeed;
    
    currentMoveTween = transform.DOMove(attackPosition, moveDuration)
        .SetEase(animationConfig.moveEase)
        .OnUpdate(() => {
            // 若已接近目标，立即切换到攻击阶段
            if (Vector3.Distance(transform.position, attackPosition) <= 0.1f) {
                transform.position = attackPosition;
                currentMoveTween.Kill();
                
                // ↓ 无缝切换到攻击 - 清除walk动画残留
                isForceAttackAnimation = true;
                CutImmediatelyForAttack();  // 清轨+复位Skeleton
                ExecuteAttackAtPosition(target, onAttackHit, () => {
                    // 阶段3: 攻击完成，返回原位
                    currentMoveTween = transform.DOMove(originalPosition, moveDuration)
                        .OnComplete(() => {
                            isAnimating = false;
                            PlayIdleAnimation();
                            onComplete?.Invoke();
                        });
                });
            }
        });
}
```

**关键时间轴**:
```
时间      事件
────────────────────────────────────────────
  0ms   ├─ PlayWalkAnimation()
        │  SkeletonAnimation.SetAnimation("walk", loop=true)
        │
100ms   ├─ Walk动画播放中 (DOMove进行中)
        │  Position: 初始位置 → 攻击位置
        │
~500ms  ├─ 抵达攻击位置（或OnUpdate阈值触发）
        │  ├─ CutImmediatelyForAttack()
        │  │  ├─ AnimationState.ClearTracks()
        │  │  ├─ Skeleton.SetToSetupPose()
        │  │  └─ AnimationState.Apply() + UpdateWorldTransform()
        │  │
        │  └─ ExecuteAttackAtPosition()
        │     └─ PlayAttackAnimation()
        │        SkeletonAnimation.SetAnimation("attack", loop=false)
        │
~650ms  ├─ 攻击动画播放中
        │  OnSpineEvent() 触发攻击命中事件
        │
~750ms  ├─ 攻击动画完成
        │  OnSpineAnimationComplete() 触发
        │  └─ ProcessAttackHit() 执行伤害计算
        │     └─ ResolveAttack() 掷骰 + 伤害结算
        │
~800ms  ├─ 返回原位移动开始
        │  PlayWalkAnimation()
        │  DOMove(originalPosition)
        │
~1300ms ├─ 返回到原位
        │  PlayIdleAnimation()
        │
~1400ms └─ 回合完成，进入下一角色
```

### 2.4 攻击执行的核心逻辑

**文件**: `DND_CharacterAdapter.cs`

```csharp
// 步骤 4: 统一的攻击执行逻辑
private void ExecuteAttackAtPosition(Transform target, System.Action onAttackHit = null, System.Action onComplete = null)
{
    // 4.1 预处理: 上锁 + 清轨
    isForceAttackAnimation = true;
    CutImmediatelyForAttack();
    
    // 4.2 播放攻击动画
    PlayAttackAnimation();  // 设置 SkeletonAnimation.SetAnimation("attack", loop=false)
    
    // 4.3 获取攻击动画时长
    string actualAttackAnimName = FindBestAttackAnimationName();
    float attackAnimationDuration = GetAnimationDuration(actualAttackAnimName);
    
    // 4.4 设置攻击命中回调（绑定到 OnAttackHit 事件）
    tempAttackHitCallback = () => {
        if (hasAttackHitTriggered) return;
        hasAttackHitTriggered = true;
        Debug.Log("攻击命中事件触发");
        onAttackHit?.Invoke();  // ← 调用 ProcessAttackHit()
    };
    OnAttackHit += tempAttackHitCallback;
    
    // 4.5 备用触发器（防止Spine事件丢失）
    DOVirtual.DelayedCall(attackAnimationDuration * 0.5f, () => {
        if (tempAttackHitCallback != null && !hasAttackHitTriggered) {
            tempAttackHitCallback.Invoke();  // 若Spine事件未触发，备用触发
        }
    });
    
    // 4.6 设置攻击完成回调
    tempAnimCompleteCallback = () => {
        if (hasAttackCompleteTriggered) return;
        hasAttackCompleteTriggered = true;
        
        isForceAttackAnimation = false;  // 解除锁
        onComplete?.Invoke();  // ← 执行后续逻辑（返回原位或回合结束）
    };
    OnAnimationComplete += tempAnimCompleteCallback;
    
    // 4.7 备用完成触发器
    DOVirtual.DelayedCall(attackAnimationDuration + 0.1f, () => {
        if (tempAnimCompleteCallback != null && !hasAttackCompleteTriggered) {
            tempAnimCompleteCallback.Invoke();
        }
    });
}
```

### 2.5 动画播放逻辑

**文件**: `DND_CharacterAdapter.cs`

```csharp
// 步骤 5: 基��动画播放方法

// ===== 战斗动画 =====
public void PlayAttackAnimation()
{
    if (IsTerminalState()) return;  // 死亡/昏迷禁止
    if (isForceAttackAnimation) {
        Debug.Log("攻击动画已上锁，忽略");
        return;
    }
    
    string attackAnimName = FindBestAttackAnimationName();
    if (!string.IsNullOrEmpty(attackAnimName)) {
        isForceAttackAnimation = true;
        PlayAnimation(attackAnimName, false);  // loop=false
    }
}

public void PlayHitAnimation()
{
    if (characterStats.IsDownOrDead()) return;  // 已死亡禁止
    if (characterStats.HasStatusEffect(StatusEffectType.Unconscious)) return;
    
    var hitName = animationConfig.hitAnimation ?? "hit";
    PlayAnimation(hitName, false);
}

public void PlayDeathAnimation()
{
    // 尝试匹配死亡相关动画
    string chosen = FindBestAnimationName(
        animationConfig.deathAnimation,
        new[] { "death", "Death", "die", "Lose", "KO" }
    );
    
    // 清轨+复位
    skeletonAnimation.AnimationState.ClearTracks();
    skeletonAnimation.Skeleton.SetToSetupPose();
    
    // 播放死亡动画（不循环）
    CurrentState = CharacterState.Death;
    PlayAnimation(chosen, false);
}

public void PlayUnconsciousAnimation()
{
    string chosen = FindBestAnimationName(
        animationConfig.unconsciousAnimation,
        new[] { "unconscious", "knockdown", "LoseLoop" }
    );
    
    skeletonAnimation.AnimationState.ClearTracks();
    CurrentState = CharacterState.Unconscious;
    PlayAnimation(chosen, true);  // loop=true
}

// ===== 实际播放 =====
private void PlayAnimation(string animationName, bool loop)
{
    if (skeletonAnimation == null) return;
    
    try {
        skeletonAnimation.AnimationState.SetAnimation(0, animationName, loop);
        
        // 即时应用（不等下一帧）
        skeletonAnimation.AnimationState.Apply(skeletonAnimation.Skeleton);
        skeletonAnimation.Skeleton.UpdateWorldTransform();
        skeletonAnimation.Update(0f);
    }
    catch (Exception ex) {
        Debug.LogWarning($"播放动画 '{animationName}' 失败: {ex.Message}");
    }
}
```

### 2.6 伤害处理与结算阶段

**文件**: `AutoBattleAI.cs` → `HorizontalCombatRules.cs` → `DamageEventChannel_SO.cs`

```csharp
// 步骤 6: 处理攻击命中
private void ProcessAttackHit(CharacterStats attacker, CharacterStats target, bool isMeleeAttack)
{
    // 6.1 检查目标状态
    int advantageFlag = 0;
    if (target.HasStatusEffect(StatusEffectType.Unconscious)) {
        advantageFlag = isMeleeAttack ? 1 : -1;  // 优势/劣势掷骰
    }
    
    // 6.2 执行攻击结算 - 命中判定 + 伤害计算
    var attackResult = HorizontalCombatRules.ResolveAttack(
        attacker, 
        target, 
        advantageFlag, 
        isMeleeAttack
    );
    
    // 6.3 如果命中，应用伤害
    if (attackResult.isHit) {
        int damage = attackResult.damage;
        bool isCritical = attackResult.isCritical;
        
        Debug.Log($"{attacker.GetDisplayName()} 命中 {target.GetDisplayName()}: {damage} 点伤害");
        
        // 发送伤害事件
        target.ReceiveDamage(damage, isCritical);
    }
}

// 步骤 6.2: 攻击结算（骰子 + 伤害）
public static AttackResult ResolveAttack(
    CharacterStats attacker, 
    CharacterStats target, 
    int advantageFlag = 0,
    bool isMeleeAttack = true
)
{
    // 6.2.1 确定攻击属性
    bool isSpell = attacker.template.defaultAttackType == DefaultAttackType.Spell;
    var weapon = FindEquippedWeapon(attacker);
    
    // 6.2.2 计算攻击加值
    int attackBonus = GetAttackBonus(attacker, isMeleeAttack, out string hitAbility, weapon);
    
    // 6.2.3 掷骰（d20 + 修正）
    int roll1 = Random.Range(1, 21);
    int roll2 = Random.Range(1, 21);
    int d20 = (advantageFlag > 0) ? Mathf.Max(roll1, roll2) : roll1;
    int totalAttack = d20 + attackBonus;
    
    // 6.2.4 暴击判定
    bool isCritical = (d20 == 20);
    
    // 6.2.5 命中判定 (vs 目标AC)
    int targetAc = target.CurrentArmorClass;
    bool isHit = isCritical || totalAttack >= targetAc;
    
    // 6.2.6 伤害计算（如果命中）
    if (isHit) {
        int damage = CalculateDamageUnified(
            attacker, 
            isCritical, 
            isSpell, 
            hitAbility, 
            weapon
        );
        
        return new AttackResult {
            isHit = true,
            damage = damage,
            isCritical = isCritical,
            description = isCritical ? "暴击命中！" : "命中！",
            damageType = isSpell ? DamageType.Force : DamageType.Bludgeoning
        };
    }
    
    return new AttackResult {
        isHit = false,
        damage = 0,
        isCritical = false,
        description = "攻击未命中"
    };
}

// 步骤 6.3: 应用伤害（触发受击动画）
// [CharacterStats.cs]
private void ReceiveDamage(int damageAmount, bool isCritical)
{
    currentHitPoints -= damageAmount;
    
    // 发布伤害事件
    var channel = damageEventChannel;  // Inspector 拖拽的通道
    if (channel != null) {
        var info = new DamageInfo(this, attacker, damageAmount, isCritical);
        channel.RaiseEvent(info);  // ← 触发所有订阅者
    }
    
    // 触发受击动画
    var adapter = GetComponent<DND_CharacterAdapter>();
    if (adapter != null) {
        adapter.PlayHitAnimation();  // 播放受击动画
    }
    
    // 检查是否死亡
    if (currentHitPoints <= 0) {
        BecomeUnconsciousOrDead();
    }
}
```

## 🎬 3. Spine 事件触发链路

**文件**: `DND_CharacterAdapter.cs`

```csharp
// 步骤 7: Spine事件回调
void OnEnable()
{
    if (skeletonAnimation != null && !spineEventsHooked) {
        skeletonAnimation.AnimationState.Event += OnSpineEvent;
        skeletonAnimation.AnimationState.Complete += OnSpineAnimationComplete;
        spineEventsHooked = true;
    }
}

void OnSpineEvent(TrackEntry trackEntry, Spine.Event e)
{
    string eventName = e.Data.Name;
    
    // 7.1 识别攻击命中事件（多重命名支持）
    bool isAttackEvent = eventName.ToLower().Contains("atk") || 
                         eventName.ToLower().Contains("attack") ||
                         eventName.ToLower().Contains("damage");
    
    if (isAttackEvent) {
        // 触发攻击命中事件
        OnAttackHit?.Invoke();  // ← 调用 ProcessAttackHit()
        return;
    }
    
    // 7.2 其他事件（状态切换、脚步声等）
    if (eventName == animationConfig.stateChangeEvent) {
        OnStateChanged?.Invoke(e.String ?? "");
    }
}

void OnSpineAnimationComplete(TrackEntry trackEntry)
{
    string completedAnimationName = trackEntry.Animation.Name;
    
    // 7.3 识别动画完成
    if (completedAnimationName == animationConfig.attackAnimation ||
        completedAnimationName == animationConfig.hitAnimation) {
        
        OnAnimationComplete?.Invoke();  // ← 调用 ExecuteAttackAtPosition() 的完成回调
        
        // 若角色未死亡，自动切回Idle
        if (!characterStats.IsDownOrDead()) {
            PlayIdleAnimation();
        }
    }
}
```

## 🔐 4. 动画锁定机制

**目的**: 防止在攻击/移动期间被其他动画覆盖

```csharp
// 核心锁定标志
private bool isForceAttackAnimation = false;  // 攻击期间禁止切换
private bool isAnimating = false;             // 正在执行动画序列

// 检查机制
public void PlayWalkAnimation()
{
    if (IsTerminalState()) return;           // 死亡/昏迷禁止
    if (isForceAttackAnimation) {
        Debug.Log("攻击动画锁定，无法切换到Walk");
        return;
    }
    PlayAnimation("walk", true);
}

public void PlayIdleAnimation()
{
    if (IsTerminalState()) return;           // 死亡/昏迷禁止
    if (isForceAttackAnimation) {
        Debug.Log("攻击动画锁定，无法切换到Idle");
        return;
    }
    PlayAnimation("idle", true);
}

// 清轨无缝切换
private void CutImmediatelyForAttack()
{
    // 清除所有轨道，避免残留的Walk动画在混合时显示
    skeletonAnimation.AnimationState.ClearTracks();
    skeletonAnimation.Skeleton.SetToSetupPose();
    skeletonAnimation.AnimationState.Apply(skeletonAnimation.Skeleton);
    skeletonAnimation.Skeleton.UpdateWorldTransform();
}
```

## 📝 10. 常见问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|--------|
| 攻击动画不播放 | animationConfig为空 或 动画名不匹配 | 检查SO配置，确保动画名与Spine一致 |
| 受击动画被攻击覆盖 | 缺少 isForceAttackAnimation 锁 | 在 PlayAttackAnimation() 设置锁，在动画完成时释放 |
| 位移Tween未完成就播放攻击 | 移动阈值太大 | 调整 `arriveSnapThreshold = 0.1f` |
| 伤害事件未触发 | DamageEventChannel 未赋值 | 在HorizontalBattleFormationManager或CharacterStats上赋值 |
| 死亡动画播放时还在运动 | 未清除旧Tween | 在 PlayDeathAnimation() 调用 `currentMoveTween.Kill()` |
| Spine事件未触发 | 动画中未定义事件 | 在Spine中编辑事件，或启用备用触发器 |

## 🎯 总结

战斗动画调用的核心链路:

```
回合轮询 → AI决策 → 位移动画 → 攻击动画 → 伤害计算 → 受击动画 → 死亡判定 → 状态更新
```

**关键设计原则**:
1. **事件驱动**: 避免协程，使用事件和DOTween
2. **状态锁定**: 防止动画冲突
3. **备用触发**: 处理Spine事件丢失情况
4. **无缝切换**: 清轨+复位确保动画连贯
5. **参数化**: SO配置解耦美术资产和代码

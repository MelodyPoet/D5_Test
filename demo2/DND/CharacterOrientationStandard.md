# 角色朝向统一规范（最终版本）

## 设计原则
采用"统一预制体朝向 + 代码单点翻转"方案，解决素材源文件朝向不一致的问题。

## 朝向标准

### 1. 预制体制作规范
- **所有角色预制体**（玩家 + 敌人）：统一面向右侧
- **不依赖素材源文件朝向**：无论原始动画朝向如何，预制体都调整为面向右侧
- **Spine预制体设置**：保持 Initial Flip X = false（统一默认值）

### 2. 代码朝向处理
- **玩家角色**：保持预制体原始朝向（面向右侧）
- **敌人角色**：在实例化时通过 Transform.localScale.x 翻转朝向（面向左侧）

## 实现方案

### 预制体制作要求
1. **统一朝向**：所有角色预制体都面向右侧
2. **Spine设置**：Initial Flip X = false（统一默认值）
3. **不受素材限制**：如果素材本身朝向左侧，在预制体中手动调整为右侧

### 代码实现
```csharp
// 玩家：保持原始朝向（面向右侧）
instance.transform.localScale = originalScale;

// 敌人：翻转X轴朝向（面向左侧）
Vector3 enemyScale = instance.transform.localScale;
enemyScale.x = -Mathf.Abs(enemyScale.x); // 确保为负值
instance.transform.localScale = enemyScale;
```

## 优势

### 1. **解决素材不一致问题**
- 不依赖原始动画文件的朝向
- 预制体阶段统一调整为右侧

### 2. **代码逻辑简单**
- 只在敌人实例化时做一次翻转
- 避免了复杂的初始化时机判断
- 没有Spine skeleton.ScaleX的异步问题

### 3. **维护性强**
- 朝向逻辑集中在一个地方
- 新增角色只需遵循预制体朝向规范
- 出问题时容易定位和修复

### 4. **兼容性好**
- 支持所有类型的角色（Spine/非Spine）
- 不依赖特定的Spine版本或设置
- 适用于各种素材来源
